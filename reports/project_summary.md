# Project Summary
## Student Performance Prediction & Analytics Using Machine Learning

**IBM SkillsBuild Data Analytics with AI Internship 2026 — AICTE**

---

## Abstract

This project presents a complete end-to-end data analytics and machine learning system
for predicting and analysing student academic performance. Using a synthetic dataset of
approximately 1,200 student records with 19 features (academic, lifestyle, and demographic),
the system demonstrates the full data science pipeline: data cleaning, exploratory data
analysis, feature engineering, supervised learning (regression and classification),
unsupervised learning (K-Means clustering), model evaluation, automated AI insight
generation, an interactive Streamlit prediction interface, and a Power BI executive
dashboard. All data is synthetic and generated for educational purposes. No real student
information was used.

**Keywords:** Student Performance Prediction, Machine Learning, Data Analytics,
Random Forest, K-Means Clustering, Streamlit, Power BI, IBM SkillsBuild, AICTE
